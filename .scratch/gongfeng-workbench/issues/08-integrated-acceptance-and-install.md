**Blocked by:** 04 — 克隆仓库并创建项目；06 — TAPD 关联与 CI 摘要；07 — 独立工作区 Review 派发。

- [x] 如复用了 GitHub 插件代码或实质部分，内部交付内容保留所需版权和完整 MIT 声明，记录来源版本；不把凭据或私有响应写入包、日志或截图。
- [x] 交付与实际代码/制品版本绑定的验收记录、通过项、未验证项及阻塞。安装说明包含服务端连接配置和必要 Git 访问条件；规格和本地任务不迁入 TAPD。
