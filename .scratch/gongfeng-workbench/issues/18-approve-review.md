# 同意评审

Status: ready-for-human
Blocked by: 17-edit-reviewers

用户明确要求补充同意按钮，并提供四种意见的弹窗截图。默认同意，可切换需要修改／明确拒绝／评论，附言选填，点击确认才提交。用户随后明确：当前账号不是评审人时隐藏评审按钮及提示；已同意账号仍可再次发表其他意见。不自动加入评审人、不合入 MR。

弹窗固定打开时的源 SHA 和评审版本；服务端重新核对账号、站点、源 SHA 和评审版本，再以白名单事件调用专用 PUT summary 端点。不提供任意事件／路径透传。写请求不自动重试；重新读取本人实际意见，未知结果提示刷新核对。API 没有已核实的原子 SHA 条件参数，不宣称核对与写入之间完全无竞争窗口。

通过业务 RPC 模拟 HTTP 验证正常同意、非评审人、重复同意、版本移动、权限错误和结果未知。真实客户端只检查确认／取消路径，不提交真实审批。

## Comments

2026-10-23：四种意见和附言已实现。真实浏览器验证非评审人隐藏入口、评审人可打开弹窗，默认同意、四选一及取消不写入通过；模拟 HTTP 验证实际提交端点和失败行为。真实业务 MR 提交留作人工验收，详见 [评审操作验证](../../../docs/review-actions-validation.md)。
