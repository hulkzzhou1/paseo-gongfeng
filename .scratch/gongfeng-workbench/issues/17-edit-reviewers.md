# 编辑评审人与概览卡片

Status: ready-for-human
Blocked by: 无

## 用户要求

- 审查卡片提供编辑按钮，可添加和移除普通评审人及必要评审人；保存才回写工蜂，取消不提交。
- Agent Review 移出独立 tab，改为概览内独立卡片，保留派发／历史／恢复行为。
- 描述使用独立卡片。
- 概览各卡片及文件／讨论分区统一使用 TAPD 同款强调边框、标题栏和图标，通过共用组件保持一致。

本任务明确授权的远程写能力为评审人管理，优先内部版、直接 OpenAPI；后续用户补充授权的四种评审意见由任务 18 实现。两项均不包含合入、发布 MR 或修改项目成员权限。

## 最小实现

- 搜索有项目权限的成员（含继承），下拉内搜索，按普通／必要类型加入草稿名单；移除和类型调整在草稿中进行。
- 保存携带工蜂站点、账号、MR 身份及名单版本；服务端重新读取并核对，旧版本不提交。修改与站点切换共用串行队列。
- API 仅新增 POST batch_invite 和 DELETE dismissals，写请求不自动重试。先处理需变更类型的旧项，再邀请，最后移除离开的评审人；任何失败停止后续步骤，读取实际名单并提示核对。无远程事务承诺，不自动回滚或覆盖第三方新增人员。
- 验证最终名单和必要类型，不能把 200 响应中的 fail_list 伪装成功。凭据和原始上游错误不回传客户端。
- 原名单、输入角色、重复 ID、数组长度、分页、账号／站点隔离均验证。新增可选字段不得破坏既有 Review 历史。

## 验证

业务 RPC 集成测试使用临时凭据和模拟 HTTP，覆盖搜索、两种邀请、两种移除、类型变化、过期名单、权限、部分失败、未知结果及无自动重试。真实客户端只验打开／搜索／草稿／取消，不更改真实业务 MR 名单，不新增模型会话。最终运行 npm run check，检查深浅主题及窄屏。
