# 指定仓库的全部 MR 漏查

Status: ready-for-human
Blocked by: 无

用户在 e2e 仓库反馈“全部”没有 MR，而个人关系可以看到。真实只读复现：相同仓库和开放状态，全部首屏0条／扫描20条；我创建2条、我参与评审3条。根因是先分页全局 dashboard 再本地过滤仓库，其他项目挤占首屏，并非权限失败。

指定仓库的“全部”改为项目 MR 接口，在服务端分页前限定仓库，不加作者／评审人限制。沿用关联校验、账号／站点隔离、搜索、开放状态包含 reopened 与明确错误，不把个人关系合并冒充全部。未选仓库及个人视图仍沿用已验证的 dashboard。项目接口 state=all/开放扫描时不传 state，按 updated_at 降序。

验证：先运行真实 e2e 首屏断言失败，再加真实 RPC 边界的模拟 HTTP 回归并观察失败；修复后真实 e2e 全部11条，我创建2条、我参与评审3条。继续验证浏览器仓库筛选和状态／搜索组合，不修改真实 MR。
