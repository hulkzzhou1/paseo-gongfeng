# 自定义工蜂站点与公开源码

Status: ready-for-human
Blocked by: 无

## 用户确认

先公开 GitHub 源码，不申请插件目录收录。移除产品中的“内部工蜂专用”描述，改为设置工蜂站点地址后搜索添加仓库。保持既有安装可用。既有决策：账号、仓库关联、历史按实例隔离，公开仓库采用干净初始提交和 MIT，不导入内部历史。

## 最小范围

设置 HTTPS 站点根地址（不含 API 路径），使用相同工蜂 OpenAPI v3；新站点单独验证 Token，不向新地址发送旧站点凭据，不跟随 HTTP 重定向。保存失败保持原配置，已保存站点可复用各自凭据。旧纯 Token 文件归属旧默认站点。API、MR URL、Git remote 匹配和 SSH 克隆使用当前站点；不新增自定义 SSH 端口配置。

按站点保留仓库列表／关联、克隆与 Review 历史，站点切换期间的本地写入操作串行，旧页面引用校验站点。TAPD 未知站点不生成内部链接，不承诺所有工蜂部署版本接口相同。

公开快照只包含审阅过的源码、测试、开发支持、公开说明及许可证，排除内部验收记录、旧历史、凭据及实际私有数据。验证后推送用户已指定 GitHub 仓库并公开。原工作空间保留内部历史。

## 验收

- 地址边界、跨站 Token 隔离、旧配置迁移、切换失败与重载。
- 相同账号／仓库／MR ID 在两站点不串数据，旧操作拒绝恢复到另一站点。
- MR 链接、仓库匹配、克隆 remote 跟随配置，保留既有内部站点回归。
- 全套检查与实际设置 UI；公网账号链路未实测需明确说明。
- 干净公开提交、GitHub 可见性和代码内容核查，不改当前 daemon 安装来源。

## 结果

已实现站点配置与隔离；工作目录和全新公开快照均通过 131 项测试和类型检查，原真实账号只读连接成功。配置表单的实际点击因浏览器自动化宿主断开暂未验收，公网完整链路和原生手机限制保留。

GitHub 已公开，main 初始提交 `9574721`，66 个文件、单一根提交，不包含内部历史和验收记录。采用 MIT，保留 private:true 防止 npm 意外发布，未申请插件目录。详见 [自定义站点验证](../../../docs/custom-site-validation.md) 和 [公开交付](../../../docs/community-publish.md)。
