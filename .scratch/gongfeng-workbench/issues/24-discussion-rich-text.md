# 讨论正文渲染

Status: ready-for-human
Blocked by: 无

用户截图中的机器人讨论包含 Markdown 和 HTML 徽章／链接，旧版直接以 Text 输出，导致标题标记和 HTML 标签裸露。讨论与完整描述共用正文渲染，支持常见标题、列表、引用、分隔线、粗体、行内与围栏代码，以及受限 HTML 图片、链接和实体。仅构建 React Native 的已知元素，不注入原始 HTML，不执行脚本或事件属性；URL 先解码再校验，图片仅HTTPS且不携OpenAPI凭据，失败显示可读标签。

五项纯函数回归（含异常长未闭合标记防卡顿）已先失败后通过。真实服务器浏览器对用户给定MR样本已验证20段正文、12个标题、5张徽章加载，无原始HTML／Markdown标题标记或横向溢出。390px窄屏复核通过。讨论仍按页读取，正文过长分段展开，不宣称完整CommonMark或所有HTML标签支持。
