# 工蜂工作台源码预览

Status: ready-for-human

## 范围

通过工蜂 HTTPS 站点根地址和 Private Token，读取仓库、MR、差异、讨论及可选的 TAPD／CI 信息。用户搜索添加仓库并关联本地 Paseo 项目；同仓库允许多份本地项目，每个项目最多对应一个仓库。

Review 派发需用户选择项目和预设；默认在独立目录核对固定版本，失败后可明确选择仅 diff。保留已有资源供幂等恢复，不自动批准、合入或触发流水线。

凭据仅服务端保存，按站点隔离，切换失败保留原配置。关联与历史也按站点隔离，相同账号或仓库 ID 不合并。已有安装自动归属原站点。

## 验收边界

自动化和已执行验证见 [公开验证说明](../../docs/validation.md)。Status 为 ready-for-human 表示需要继续验收新增站点表单、公网部署与原生手机，不表示这些场景已经通过。
