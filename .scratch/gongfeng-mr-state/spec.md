# MR 关闭／重新打开

Status: ready-for-human

## 已确认范围

用户确认界面＋MCP、小确认弹窗仅切换状态、共享RPC／标准MCP／真实UI三个验证边界，正式审查基准 d3a8742。暂不执行真实MR写操作，不调用模型；社区发布继续等待宿主MCP PR接受。

开放（opened／reopened）MR可关闭，closed可重开；merged／locked／未知状态不提供操作。概览使用紧凑按钮和现有原生弹窗；重开提示可能按最新OWNERS重置评审规则。提交中禁用，成功刷新列表和详情；失败／结果未知保留提示，回读核对，不自动重试。

RPC与MCP共用内部业务处理、凭据和写队列；输入包含站点、当前账号、目标项目和全局mrId、最新详情的状态版本，以及close／reopen事件。写入前重新读取并复核身份、版本及允许的状态。仅发送文档化state_event query，不附带其他MR字段；MCP要求confirm:true且标为写操作。权限最终由工蜂判定，客户端不把作者或评审人身份当作充分授权；权限失败明确反馈。

官方契约和未明确限制见 docs/mr-lifecycle-research.md。预检查与远程写入不是原子事务，不宣称消除全部并发窗口；重开保留工蜂自身规则和集成副作用。

## 验证与交付
