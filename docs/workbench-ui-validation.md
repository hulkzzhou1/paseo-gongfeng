## 实现范围

- 紧凑 MR 列表突出标题、状态和选中项，显示所有者英文账号；右上角打开同一份连接设置。
- MR 详情为悬浮右抽屉，不改变列表宽度；200ms 滑入、160ms 滑出，遮罩渐变，减少动态效果时跳过动画。Web 键盘焦点循环、Esc 关闭和关闭后返回来源行。
- 描述默认 120 Unicode 字符摘要。全文分段显示基础 Markdown，保留截断提示和原站链接。桌面弹窗最高 1040px，窄屏使用宿主 sheet。Paseo 0.12 未提供宽度参数，Web 仅调整描述所属 dialog 的尺寸，卸载恢复；升级宿主时需回归这个兼容点。
- 差异有双侧行号、增删底色、文件折叠、横向滚动／换行和分批加载；版本信息默认收起，异常与不完整提示保持可见。
- TAPD 独立强调边框与标识，工作项标题、类型、状态及原站链接分层；CI 保持独立检查列表。
- 仓库管理仅显示已添加列表。添加弹窗使用一个组合下拉，展开后内部搜索，选中后收起；每个仓库独立关联项目。旧关联自动纳入列表，解除关联不删除已添加记录。

## 保留的限制

浏览器窄屏不等于原生 iOS／Android 验收；完整屏幕阅读器、所有键盘路径及 reduce-motion 的真实设备切换未穷举。描述是基础 Markdown，复杂表格／嵌套语法可能作为文本展示；差异是增删着色，未增加语法高亮依赖。

本轮没有重演新 Review 启动、全新目录首次 UI clone、真实换账号失败与故障恢复，也不证明公网工蜂可用。旧集成验收待办继续保留，见 [集成验收](integrated-acceptance.md)。
