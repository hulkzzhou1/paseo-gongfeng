# 讨论正文渲染验证

日期：2026-10-23。Paseo daemon／Web UI 0.12.0。

讨论以前直接输出 `note.body`；现与完整描述共用 `RichText`，Markdown 标题、列表、引用、分隔线、粗体、行内／围栏代码，以及机器人 HTML 徽章／链接按内容展示。描述宽弹窗逻辑仍只在描述入口使用，不影响评论卡片。

渲染器仅生成已知 React Native 元素，不使用原始 HTML 注入。脚本等主动内容丢弃，未知标签不传递属性；链接／图片实体解码后校验协议和凭据，图片仅 HTTPS，不附 OpenAPI Token。图片失败显示标签；徽章无 alt 时从标准徽章路径提取可读提示。代码里的 HTML 保持字面文本。

五项自动化覆盖异常长的未闭合标记（10万字符级），以及 Markdown 与 HTML 混排、危险链接及事件属性、实体解码、代码字面内容、相对链接和嵌套图片链接。服务器浏览器使用用户给定的 MR 样本，只读核对20段正文、12个标题及5张已加载徽章；没有可见原始标签或标题前缀，没有页面横向溢出；390px 窄屏复核20段正文，同样无原始标记和横向溢出。未点击机器人链接或执行远程状态操作，也未复制真实正文／账号／仓库到本记录。

这是常见 Markdown 与受限 HTML 的展示支持，不是浏览器 HTML 执行器或完整 CommonMark 实现；原生手机仍待验收。

2026-10-23 正式审查后修复跨空行pre／行内代码边界与异常HTML重复扫描；见[修复验证](compact-buttons-rich-text-validation.md)。
