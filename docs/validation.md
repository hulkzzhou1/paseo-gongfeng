# 预览版验证范围

Node.js 24、Paseo daemon 与 Web UI 0.12.0。类型检查和 131 项自动化测试通过；自动化使用临时数据、真实本地 Git 及模拟 HTTP，不需要真实 Token 或模型调用。

已有工蜂部署验证过连接、查询、仓库关联与克隆、固定版本 Review 和幂等恢复。工作台改版验证过 Web 桌面／390px 窄屏、悬浮抽屉动画、描述弹窗、仓库下拉和关联操作。

自定义站点新增测试覆盖地址验证、凭据隔离、旧配置迁移、站点切换失败、相同账号和仓库 ID 的数据隔离、历史恢复限制，以及自定义 SSH 主机的本地克隆。已有账号只读连接仍成功。

新增地址字段的真实 UI 点击尚未验收，测试时浏览器自动化宿主已断开。公网 SaaS 完整账号链路、原生手机、所有键盘与可访问性路径、其他部署版本未验收。SSH 使用站点主机和标准端口，不支持独立 SSH 主机／端口配置。

发布内容不包括实际账号、业务仓库、MR 正文或运行记录，也不等于已申请 Paseo 插件目录收录。
