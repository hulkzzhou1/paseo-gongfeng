# 预览版验证范围

2026-10-23：Node.js 24、Paseo daemon 与 Web UI 0.12.0。本地任务状态、类型检查和 152 项自动化测试通过；自动化使用临时数据、真实本地 Git 及模拟 HTTP，不需要真实 Token 或模型调用。

已有工蜂部署验证过连接、查询、仓库关联与克隆、固定版本 Review 和幂等恢复。工作台改版验证过 Web 桌面／390px 窄屏、悬浮抽屉动画、描述弹窗、仓库下拉和关联操作。

自定义站点新增测试覆盖地址验证、凭据隔离、旧配置迁移、站点切换失败、相同账号和仓库 ID 的数据隔离、历史恢复限制，以及自定义 SSH 主机的本地克隆。已有账号只读连接仍成功。

浏览器连接恢复后已补验自定义地址输入、无效地址校验、设置弹窗、仓库组合下拉搜索、选择与关联核验；没有保存测试站点或重新输入凭据。

MR 概览统一卡片展示代码评审、描述、TAPD、CI 和 Agent Review，Agent Review 不再使用独立 tab。实际单击详情右上角刷新，确认七类读取均重取，没有派发 Agent。评审规则缺失或人员类型未知时保留待核对；同一人员的重复关系合并，意见冲突不冒充同意。旧版持久化 Review 快照恢复测试通过。

新增评审人编辑与四种意见的业务 RPC 集成测试覆盖普通／必要人员的添加、移除和类型调整、版本过期、账号站点隔离、权限、部分失败、未知结果，以及同意、需要修改、明确拒绝和评论。写请求使用专用端点且不自动重试；空附言重复同意不会多发请求。真实浏览器仅验证搜索、草稿、类型调整、移除、意见单选与取消，没有对业务 MR 执行保存或提交。当前账号不是评审人时，评审按钮和提示隐藏。

Light／系统暗色、1280px 桌面及 390px 窄屏检查通过。窄屏评审卡片宽365px，意见弹窗内容宽342px，无横向溢出；人员列表与宿主弹窗可滚动到保存／取消。验收后恢复原主题和桌面视口。这些浏览器检查不等于原生手机或完整可访问性验收。

真实业务 MR 的远程评审人写入和意见提交尚未验收；人员保存可能部分成功，版本检查与写入之间没有已验证的原子条件保证。公网 SaaS 完整账号链路、原生手机、所有键盘与可访问性路径、其他部署版本未验收。SSH 使用站点主机和标准端口，不支持独立 SSH 主机／端口配置。

发布内容不包括实际账号、业务仓库、MR 正文或运行记录，也不等于已申请 Paseo 插件目录收录。

最新兼容性修复恢复旧默认站点对 HTTP Git remote 的身份识别，API 仍使用 HTTPS；新增回归测试验证关联在重载后保持有效，错误主机、非默认 HTTP 端口和错误仓库路径仍拒绝匹配。
