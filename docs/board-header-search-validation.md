# 顶部布局、全部 MR 与搜索验证

2026-10-23 修正：指定仓库的“全部”直接使用项目 MR 接口，避免全局分页后筛选导致首屏为空；仅未选仓库或个人关系视图仍使用 dashboard。见[当前集成验收](integrated-acceptance.md)。下文全局分页后过滤的历史描述不再适用于该场景。

日期：2026-10-23。基于 `056576f` 后的本轮调整；Node.js 24、Paseo daemon／Web UI 0.12.0。没有业务 MR 写入或模型调用。

## 行为

- 参照用户提供的 GitHub 截图调整为标题操作、合并请求／仓库管理导航、集中筛选三层。默认全部可见 MR，保留我创建／我参与评审；状态收为下拉，仓库在下拉内搜索，增加 MR 搜索栏。
- 桌面按钮 28px、文字 12px，顶部约137px；窄屏保留36px按钮并换行。配置与刷新用图标按钮；仅保留右上角一个工作台刷新入口，列表独立刷新已移除。
- 加载时在页面内容区中央通过原生 ActivityIndicator 显示旋转，右上角保持普通刷新图标并禁用重复点击；结束后移除中央旋转，原列表与布局保留。更新时间保留最后成功读取值，失败显示更新未完成。界面不会把当前页数量当作全站总数。
- 插件可见名称及侧边栏改为“工蜂”，插件 ID、数据路径和既有资源身份保持不变。
- 全部关系不附带作者／评审人限制，仍由当前站点和账号权限决定结果。搜索匹配标题、仓库路径、项目内编号及作者英文账号，防抖300ms，回车立即应用。输入、关系、状态、仓库与身份进入查询键，改变条件从第一页开始。
- 此部署 dashboard 会忽略 search 参数，故服务端逐页读取并过滤；搜索时每页至多100条原始记录，保留原始分页和扫描量。未搜到时提示仍可继续；末页才表示本轮已搜索完，不只过滤客户端已加载的 MR。没有新增索引服务、仓库枚举或无限后台扫描。

## 证据

- 官方文档核对：[Dashboard MR](https://git.woa.com/help/menu/api/cr/mr_review.html) 的作者／评审人参数可选；[项目 MR](https://git.woa.com/help/menu/api/merge_requests.html) 另有标题 search，不能直接当作全局接口参数。真实只读对照中，去掉关系限制能返回其他作者；不可能匹配的关键词参数仍返回数据，证明该部署忽略该参数。只输出计数，不保存 MR 内容。
- `npm run check`：任务状态、TypeScript、155 项自动化通过；`git diff --check` 通过。新增3项业务 RPC 回归先红后绿，覆盖全部关系、其他作者／项目、空匹配页后继续找到结果、100条分页边界、大小写／空白、仓库／编号／作者匹配及超长输入；既有账号／站点与仓库隔离测试继续通过。
- 输入框阻止键盘事件冒泡的问题由实际 UI 暴露，在共用焦点边界使用捕获阶段处理，并避开输入法组合事件。回归同时验证焦点循环、嵌套弹窗不被关闭、移除监听和恢复来源焦点；真实搜索下拉 Esc 关闭及焦点返回通过。
- 服务器浏览器通过插件自带官方桥接操作，用户自行完成该独立浏览器的首次 Paseo 登录。读取或输出未涉及宿主密码／Token；没有创建浏览器 Agent、绕过手动接管或直接连接 CDP。已登录客户端和服务器浏览器都用于本轮验证，不能将两种浏览器混称同一会话。
- 桌面1280×800：包含搜索后的顶部137px，按钮28px，无横向溢出。390×844：顶部245px，按钮36px，搜索输入位于视口内，无横向溢出。Light 与系统暗色均检查过；没有保存私有页面截图。
- 实际刷新仅重取 `repositories.bindings` 和一次 `board.page`，没有 `review.start`、`review.submit`、`reviewers.save`。临时 DOM 观察捕获到内容区中央的动画与进度条，中心坐标与内容区中心一致，右上角按钮内没有进度条；结束后内容区 busy 清除、中央进度条移除。按钮28px／顶部137px，加载不改变布局；临时观察器已移除。
- 真实搜索中，当前样本标题能匹配到对应MR；清空恢复查询。无匹配词首次已搜索100条，仍保留继续搜索及未完成提示；点击后增加至200条，不冒充全局无结果。状态下拉选择已合入后当前20项均为已合入，关闭后焦点回到状态按钮。
- 详情抽屉仍悬浮显示，桌面样本宽672px，关闭控件在顶部之上可点击；未派发新的 Review 或更改真实评审状态。

## 限制

关键词是逐页扫描，不是已验证的站点全文索引；结果未到末页时需继续搜索。列表动态更新时，跨页结果不是原子快照，可刷新重查。公网 SaaS、原生 iOS／Android、所有键盘／屏幕阅读器与真实故障 UI未穷举；其他延期项仍见 [集成验收](integrated-acceptance.md)。
