# 自定义工蜂站点验证

日期：2026-10-22。范围是自定义工蜂 HTTPS 根地址及源码公开，不申请插件目录收录。

配置页填写站点与可选新 Token；新站点必须提供对应凭据，已保存站点可复用自己的 Token。服务器原子保存当前站点与各站点凭据，旧纯 Token 文件归属原默认站点。API 不跟随重定向；地址拒绝 HTTP、路径、URL 凭据、查询、片段和内嵌空白。

API、MR 链接与 SSH 主机跟随站点；SSH 端口固定使用标准端口，不提供独立主机／端口配置。站点切换与本地写入共用串行队列，进行中的克隆／Review 不会中途切站点。关联、已添加仓库、克隆与审查历史按站点区分；旧页面请求携带站点，站点变更后拒绝继续，不靠账号或仓库 ID 猜测身份。

## 证据

- `npm run check`：任务状态、TypeScript、131/131 测试通过；`git diff --check` 通过。
- 新增测试覆盖：地址边界；各站点 Token 只发往对应地址；空 Token 不沿用另一站点身份；原配置迁移、失败保留与重载；相同账号／仓库／MR ID 的关联和历史隔离；跨站点操作恢复拒绝；切站点等待本地写操作结束。
- 使用临时真实 Git 目录验证自定义 SSH 主机克隆、登记、关联及历史隔离；没有连接真实自定义 Git 服务或调用模型。
- TAPD 自定义站点不自动生成内部原站 URL；已知原站映射保留旧行为。
- 本机插件 reload running，已有真实账号只读会话 connected，旧配置可识别；没有更换 Token 或站点，没有修改用户目录。
- 新版设置页的实际点击和窄屏检查未完成：原自动化浏览器宿主已断开连接。上一轮工作台界面证据见 [界面验证](workbench-ui-validation.md)，不能替代本次新表单验收。

公网 SaaS 的真实账号链路、其他部署版本以及自定义 SSH 端口仍未验证／支持。公开版本说明这些边界，不能据此宣称公网功能验收完成。
