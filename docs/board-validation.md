# 全局 MR 看板验证

日期：2026-10-22。任务 02 的实现及只读 OpenAPI 验证记录；宿主视觉验收未执行。

## 实现

- `board.page` 按当前账号查询“我创建”和“我参与评审”，两类独立分页、加载及错误状态；评审列表包含已审查事项。
- 支持开放、已合入、已关闭、全部，按工蜂项目 ID 与 MR ID 去重；项目内 `iid` 用于展示编号及原站链接。
- 每页最多读取 20 条 MR；优先使用 `X-Next-Page`，缺少时满页允许继续读取，少于 20 条视为末页。未加载的页明确提示。
- 开放视图使用 `state=all` 并按页排除 `merged/closed`，因此包含 `reopened`；未知状态原样可辨识展示。某页没有匹配记录仍允许继续读取，不伪装为空集合。
- 账号切换后取消在途查询并清理业务查询；看板查询键含账号、关系、状态，服务端校验请求期望账号，避免把后续页追加给旧身份。
- 所有工蜂请求经共用服务器凭据层，固定主机、仅 GET、禁止跟随重定向、单次 GET 连同重试总计最多 10 秒。网络错误、429、5xx 最多尝试 3 次，默认退避 250／500 毫秒；遵守 Retry-After 秒数或 HTTP 日期，超过剩余时限时直接返回原错误，不提前重试。权限、其他 HTTP 错误及非法响应不重试；没有自动轮询，耗尽后保留手动重试。

## 官方契约与实测

来源：[MR Review 内网官方文档](https://git.woa.com/help/menu/api/cr/mr_review.html)，dashboard 路径为 `/api/v3/dashboard/merge_requests`。

使用用户已经安全配置的插件专属 Token，在服务器执行只读检查；仅记录状态、数量和布尔校验，不保存账号、私有标题、描述、仓库路径或正文。

- 响应为 `{project, merge_requests}[]`，分页大小约束 MR 数，不是项目分组数。
- 两种用户过滤分别采用 `author_user_name` / `reviewer_user_name`；作者列表样本的 `author.id` 均与当前账号匹配。评审查询的列表样本未直接携带评审人对象，因此未将该关系解释成精确“待我处理”。
- `per_page=2` 时，两种关系的前两页均有 2 条，页间样本无重叠；分组项目 ID 与 MR `target_project_id` 一致。
- 实测响应没有 `X-Next-Page` / `X-Total` 等分页头。通过原始 MR 条数而非去重后的条数判断是否可能有下一页。
- **`state=reopened` 实测返回了 `opened` 项，而 `state=all` 含真实 `reopened` 项。** 所以开放视图不直接依赖 `reopened` 参数，也不只查询 `opened`。
- 从实际 `board.page` 业务边界执行“两关系 × 四状态”共八个首屏请求，均成功。开放列表包含 `opened/reopened`，历史列表分别包含 `merged/closed`。评审关闭列表实际返回 2 条并报告末页；其他多数组合原始页为 20 条并报告可继续加载。

## 自动检查及待验收

- 11 项看板业务 RPC 集成测试通过：分组、身份、重复、重新打开、未知状态、历史、分页边界、账号切换、401/403/404/429/500、非 JSON、网络错误及局部失败。
- 公共凭据层抽取后，原 16 项账号连接回归测试通过；类型检查通过。
- 测试只替换 HTTP，凭据读写使用临时真实目录，从真实服务器入口注册并调用业务 RPC。
- 宿主宽屏、紧凑布局、手机及深浅主题尚未实际验收；等待主集成验证，不据代码或类型检查宣称 UI 验收通过。


## 任务 08：持久关联仓库筛选

`3edf0ce` 增加可选 repositoryId；服务端复用持久关联列表核对当前 daemon 的关系，只筛选已有关联的仓库。全局查询不要求关联或宿主项目可用。已解除最后关联时返回 stale_binding，避免把过期筛选当作空结果；同仓库多个项目不重复结果。原始扫描数量和 nextPage 在筛选前计算，空页依然可继续加载。

看板查询键进一步包含仓库及关联刷新版本；状态／仓库／账号切换和手动刷新重新读取第一页。账号成功更换会清理业务查询；仓库选项按 ID 去重，解除最后关联后刷新回到全局并提示。

任务 08 聚焦检查：看板 15 项、关联 9 项 RPC 测试与类型检查通过；真实 UI 筛选和视觉仍待验收，详见[集成验收](integrated-acceptance.md)。新增测试替换 HTTP 和宿主边界，使用临时真实凭据及关联文件；没有模拟内部过滤函数。

## 最终审查修复

新增业务 RPC 检查覆盖暂时性错误恢复与耗尽、权限／非法响应不重试、Retry-After 秒数及日期、长等待不提前请求、插件卸载中止退避，以及含重试的十秒总时限。测试仅替换 HTTP 边界，使用真实临时凭据目录；不在真实工蜂服务制造限流。最终全套结果见集成验收记录。
