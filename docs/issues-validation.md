## 已实现

- 顶部独立“议题”入口，默认开放、最近更新；汇总当前站点已添加仓库，可筛选单仓、状态、全部／我创建／指派给我，按关键词或 `#IID` 查询。逐仓请求、每批最多四仓并发、每仓分页；展示失败仓库与未加载范围，排序覆盖已加载结果。
- 悬浮详情抽屉、宽版编辑表单，描述和评论复用现有安全富文本，支持表格、只读任务清单和代码块；里程碑中的议题可进入详情，也可返回关联里程碑。
- 新建、编辑、关闭／重开，支持标题、描述、多处理人、优先级、已有标签、同仓里程碑、私密标记及独立解决状态。省略字段保留，指定空集合／空正文／空里程碑用于清空。
- 私密改普通分别使用确认弹窗和 `confirmPublic:true`；缺少明确可见性字段时拒绝解析，不将未知属性默认为普通。提交前核对当前账号、已添加仓库、全局身份和版本，人员验证复用分页仓库成员查询；写后回读，未知结果不自动重试。
- 分页评论、发表和编辑本人非系统评论，校验评论作者、系统属性及版本；他人／系统评论只读。嵌套内容范围和已知 fork 同步风险明确提示。
- UI RPC 与 MCP 共用处理器，新增八个显式工具：`list_issues`、`get_issue`、`save_issue`、`search_issue_assignees`、`list_issue_labels`、`list_issue_milestones`、`list_issue_notes`、`save_issue_note`。总工具数 35；写工具要求独立 `confirm:true`。没有暴露凭据、通用 HTTP 或 UI 内部接口。
- MCP 的默认关闭、有效关联项目中新建 Agent 注入边界保持原状；没有刷新或重启已有 Agent。查询失败隐藏旧内容，局部失败仓库不保留其历史页；检测账号／授权变化关闭编辑稿并重新核对连接。

## 专用 e2e 实际写入

仅修改本轮自建、带 `Paseo Issue acceptance` 前缀的虚构样本，不修改既有业务议题。通过正式插件 RPC 验证：

- 创建普通议题、编辑和清空正文；设为私密；不带独立确认的公开请求被拒绝，确认后可改普通。
- 关闭、重开同一议题。工蜂实际重开返回 `reopened`，已统一归为 `opened` 并补回归，未因首次回读未知结果重复重开发送。
- 设置当前账号为处理人并清空；设置 P2、解决状态；关联和解除本轮虚构里程碑。
- 清空标签通过；仓库无已有标签，因此非空标签的真实设置未验收，没有为测试创建仓库标签。非空标签设置及拒绝未知标签由受控请求覆盖。
- 发表一条虚构评论并编辑同一条自己的非系统评论；读取结果和正文一致。

验收驱动续跑时发生一次旧 revision 拒绝，源于驱动重复执行了已完成的普通属性探针；已修正驱动为按阶段恢复，并先正式读取当前版本。没有将该拒绝当作产品写入成功，也没有重试未知结果。

收尾：由真实 UI 确认关闭样本，再经正式 RPC 回读为 closed、无里程碑；本轮临时里程碑已按正式接口删除。样本议题及评论历史按事先约定保留。私有临时收据记录样本身份与步骤，不包含 Token；仓库文档不包含真实正文、账号、仓库地址或认证浏览器截图。全程 0 模型调用。
